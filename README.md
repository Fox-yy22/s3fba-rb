# s3fba-rb(rain fall blue) 雨の降りてき青    （降雨蓝）

这是一个企划的设定和剧情存储仓库，这个企划以“蔚蓝档案”为原型，大多数设定来源于该游戏

It's a site of project's settings and scripts. The project is based on Bule Archive, so many settings are form this.
